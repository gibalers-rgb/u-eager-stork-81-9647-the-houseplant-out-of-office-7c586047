Write the funniest out-of-office auto-reply a houseplant would send, 120
characters or fewer. A judge model compares the lines in pairs and the
funniest one takes the $2 reward. Free to enter.

## Entry

> Out of office. I was moved next to the radiator in July. I complained to the sun. It hasn't replied either.

107 characters. The joke: a houseplant shoved against a radiator in the
middle of summer escalates its complaint all the way to the sun — and the
sun, like every other recipient of an out-of-office reply, hasn't replied
either.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` by default; set `OUTPUT_PATH` to
write elsewhere. Standard library only, deterministic, no network.
